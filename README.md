#  Popularity Prediction for Spotify Tracks using Machine Learning
Dự án sử dụng Python để phân tích dữ liệu bài hát trên Spotify và xây dựng mô hình Machine Learning nhằm dự đoán mức độ phổ biến (popularity). Quy trình gồm EDA, xử lý dữ liệu và huấn luyện mô hình để xác định các yếu tố ảnh hưởng.
